An automated, ultra-modern portfolio website engineered with React 19, TypeScript, Tailwind CSS, Three.js 3D Solar System interactive visuals, and a **Live Content Management Admin Panel**.

---

## ✨ Features

- **🎛️ Live Admin Panel (`/admin`):** Complete in-browser CMS to update Projects, Apps, Tech Skills, Innovation Ideas, and Profile info without writing any code.
- **🌌 Interactive 3D Solar System (Three.js):** Dynamic skill spheres orbiting in 3D space with real-time physics and lighting.
- **📱 Works & Apps Showcase:** Category filtering, live demo launch, GitHub repository links, and interactive project detail modals.
- **💡 Innovation & Ideas Lab:** Showcase upcoming products, ongoing prototypes, and R&D status (MVP Ready, In Development, Concept).
- **📬 Client Booking & Inbox:** Integrated meeting schedule modal with client message routing and database persistence.
- **⚡ Vercel Serverless Ready:** Preconfigured `vercel.json` with zero-config serverless API routes (`/api/send-booking`, `/api/health`).
- **🔄 Instant Cloud Sync:** Firebase Firestore live listener with automatic fallback.
